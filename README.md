# Paradise Nursery Shopping Application

A dynamic React e-commerce application for an online plant shop built as part of the IBM Full-Stack Software Developer Professional Certificate.

## Features
- **Landing Page**: Welcome banner with company details and a "Get Started" call to action.
- **Product Catalog**: Displays 18+ houseplants across 3 categories with dynamically updated "Add to Cart" states.
- **Redux State Management**: Centralized shopping cart state using Redux Toolkit (`CartSlice.jsx`).
- **Shopping Cart**: Real-time total cost calculations, quantity adjustments, item deletions, and checkout modals.
